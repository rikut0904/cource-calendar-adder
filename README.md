# class-calendar-adder

生成プロファイル: go

## 開発

生成された構成に応じたコマンドは`Makefile`を確認してください。シークレットは`.env`へ置き、`.env.example`を共有用の見本として使います。

## 授業予定の登録

このアプリはGoogle Calendar APIを使って、授業予定を指定カレンダーへ登録します。

1. Google Cloud ConsoleでCalendar APIを有効化し、OAuthクライアント（デスクトップアプリ）のJSONをダウンロードする。
2. JSONを`credentials.json`としてプロジェクト直下に置く（または`GOOGLE_CREDENTIALS_FILE`で指定する）。
3. `.env.example`を参考に環境変数を設定する。アプリは起動時に`.env`を自動読み込みする。`GOOGLE_CALENDAR_ID=primary`なら自分の既定カレンダーに登録される。
4. `make up`を実行する。初回だけブラウザで認証し、以降は`GOOGLE_TOKEN_FILE`のトークンを再利用する。

TUIでは、学期の開始・終了日を指定して授業を複数件入力できます。授業は曜日を選択し、1〜5限と教師名を指定します。初期時刻は`08:40-10:20`、`10:35-12:15`、`13:15-14:55`、`15:10-16:50`、`17:05-18:45`です。教師名はGoogle Calendarの予定メモにも記録されます。

`s`キーの授業期間・時限設定画面から開始日・終了日と各時限を変更できます。授業追加時に、授業ごとに全期・半期を選択します。全期は開始日から終了日まで、半期は開始日から休講日・祝日を除いた7回分の授業を登録します。開始日・終了日は起動中のみ使用し、学期ごとに設定します。時限だけが`CALENDAR_SETTINGS_FILE`（既定`.calendar-settings.json`）に保存されます。曜日選択には平日のみが表示され、初期状態では土日と日本の祝日を週次予定から自動的に除外します。

`x`キーのカレンダー例外設定では、土日除外の有効・無効を切り替えられます。学校独自の休講日は`YYYY-MM-DD`、曜日変更日は`変更先日付=変更元曜日`形式で入力します。例えば`2026-04-08=月`なら、同じ週の月曜授業を除外し、4月8日（水）に単発予定を作成します。祝日計算に含まれない学校独自の休日は休講日欄へ追加してください。

授業一覧画面で`E`を押すと、カレンダー登録に必要な設定をJSONでエクスポートできます。出力にはCalendar ID、期間、時限、授業、教師、例外設定が含まれますが、OAuth認証情報やトークンは含まれません。出力先は`CALENDAR_EXPORT_FILE`で指定でき、未指定時は日時付きファイル名になります。

授業一覧画面で`I`を押すと、エクスポートしたJSONをインポートできます。インポート時に授業、期間、時限、教師、休講日、曜日変更をまとめて復元します。入力欄にはファイルパスを指定し、`CALENDAR_IMPORT_FILE`を設定している場合はそのパスが初期値になります。未設定の場合は、現在のディレクトリにある最新の`class-calendar-export*.json`を自動選択します。`~/`から始まるホームディレクトリのパスにも対応しています。異なるCalendar IDやタイムゾーンの設定ファイルは誤登録防止のため読み込みません。

授業一覧では次のキーを使用します。

- `n` / `a`: 授業を追加
- `e`: 選択中の授業を編集
- `d` / Delete: 選択中の授業を削除
- `s`: 期間・時限設定
- `x`: 土日除外、休講日、曜日変更の設定
- `I`: 設定JSONをインポート
- `E`: 設定JSONをエクスポート
- `r`: 登録前の確認画面
- `q`: 終了

確認画面でEnterを押すと、すべての予定をgoroutineとワーカープールで並列登録します。APIへのリクエストは同時実行数を制限し、レート制限や一時的なサーバーエラーが発生した場合は自動的に再試行します。登録中は進捗、成功件数、失敗件数、処理中の授業名を表示します。登録に失敗してもTUIは終了せず、結果画面から失敗分だけ再試行できます。

TUIの表示幅に合わせて枠の幅を自動調整し、長い授業名、エラー、URLなどは画面内で折り返します。日本語入力や矢印キーによるフィールド移動にも対応しています。

カレンダーIDやOAuthトークン、認証JSONはコミットしないでください。

指定カレンダーへ登録する場合は、Google Calendarの「設定と共有」→「カレンダーの統合」→「カレンダーID」に表示されるIDを`.env`の`GOOGLE_CALENDAR_ID`へ設定します。カレンダー名ではなく、`xxx@group.calendar.google.com`のようなIDを指定してください。起動時の`登録先:`表示で確認できます。
